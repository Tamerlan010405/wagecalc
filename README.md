# WageCalc

Веб-приложение для расчёта среднемесячных выплат сотрудникам за квартал и сравнения с «планкой» Росстата (федеральной и региональной). Пользователь создаёт отчёт, вводит выплаты по сотрудникам, запускает расчёт и получает результат: выполняется критерий или нет, и рекомендацию. Сохранённые отчёты доступны в истории, результат можно скачать в Excel.

## Фронтенд

Клиентская часть (`frontend/`) — основной сценарий работы с приложением:

- **Главная страница** — список сохранённых отчётов карточками, поиск по названию и организации, фильтры (квартал, организация, результат), пагинация, удаление с подтверждением.
- **Создание отчёта** — модальная форма (название, организация, квартал, год) с валидацией.
- **Страница расчёта** — таблица сотрудников: по каждому три месяца квартала, в каждом общая сумма и выплаты по ГПХ; добавление и удаление строк, проверка денежных значений на клиенте, очистка пустых строк перед отправкой.
- **Результат** — панель с планкой Росстата, средней выплатой за квартал, статусом критерия и рекомендацией, раскрываемый блок с подробным расчётом.
- **Выгрузка результата в Excel.**
- **Страница методики расчёта.**
- **Авторизация** — вход, регистрация, подтверждение кода и восстановление пароля.

## Стек

| Часть | Технологии |
|---|---|
| Frontend | React, React Router, Mantine (core, form, hooks), ExcelJS, Vite |
| Backend | Go, REST API (`/api/v1`), миграции SQL |
| База данных | PostgreSQL |
| Окружение | Docker Compose, Nginx, Mailpit (локальные письма) |

## Запуск

Нужны Docker и Docker Compose.

```bash
cp .env.example .env      # заполните значения (пароли БД, ключи)
docker compose up --build -d
```

После запуска:

- фронтенд: http://localhost:3000
- API: http://localhost:8080
- Mailpit (письма восстановления): http://localhost:8025

Подробнее о командах Docker — в [docs/docker-usage.md](docs/docker-usage.md).

Фронтенд отдельно (режим разработки):

```bash
cd frontend
npm install
npm run dev
```
